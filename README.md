# QA Portfolio · Marcus Gatti

**English** · [Português](README.pt-BR.md)

QA Engineer (web and mobile) based in Belo Horizonte, Brazil, working remotely.
This repository collects the templates, test design techniques and ways of working I use, organized along the **ISTQB CTFL v4.0 syllabus**.

> I am preparing for the CTFL v4.0 exam (planned for 2027). The syllabus is used here as a reference structure, not as a claim of certification.

---

## How to read this portfolio

Every document carries one of two labels:

| Label | Meaning |
|---|---|
| ✅ **Applied in practice** | I have used this in real projects (functional testing of web and mobile apps, Agile squads, Azure DevOps and Jira) |
| 📚 **Study reference** | Built while studying the syllabus and related standards. Not yet part of my day-to-day work |

**All examples are fictional.** They use *TrilhaFit*, an invented gym class booking app (web, Android and iOS). No client data, names, screens or IDs from any real project appear here. The techniques and decisions, where labeled ✅, are the ones I actually use.
