# Portfólio de QA · Marcus Gatti

[English](README.md) · **Português**

QA Engineer (web e mobile) em Belo Horizonte (MG), trabalhando remoto.
Este repositório reúne os templates, as técnicas de design de teste e as formas de trabalho que uso, organizados pelo **syllabus ISTQB CTFL v4.0**.

> Estou me preparando para a prova da CTFL v4.0 (prevista para 2027). O syllabus aparece aqui como estrutura de referência, não como certificação obtida.

---

## Como ler este portfólio

Todo documento traz um de dois selos:

| Selo | Significado |
|---|---|
| ✅ **Aplicado na prática** | Já usei em projeto real (teste funcional de apps web e mobile, squads ágeis, Azure DevOps e Jira) |
| 📚 **Referência de estudo** | Montado a partir do estudo do syllabus e das normas relacionadas. Ainda não faz parte do meu dia a dia |

**Todos os exemplos são fictícios.** Eles usam o *TrilhaFit*, um app inventado de reserva de aulas de academia (web, Android e iOS). Nenhum dado, nome, tela ou ID de projeto real aparece aqui. As técnicas e decisões marcadas com ✅ são as que uso de verdade.
